# OPIc IH 스피킹 트레이너

OPIc(IH · 4-4 목표) 말하기 연습용 웹앱. 크롬 음성인식으로 답변을 녹음·전사하고,
본인 Anthropic(Claude) API 키로 IH 등급 추정·문법 교정·모범답안 피드백을 받습니다.

## 특징
- OPIc IH 표준 질문 은행 (자기소개 · 묘사 · 습관 · 과거경험 · 비교 · 롤플레이 · 고난도 이슈)
- 실시간 전사 + 녹음 재생 + 전사 직접 수정
- 무료 지표: 단어수 · WPM · 문장수 · 연결어 · 군더더기 · 어휘 다양성
- AI 첨삭: 등급 추정, 5개 항목 점수, 문법 교정, 어휘 업그레이드, IH 모범답안
- 연습 기록 (localStorage)

## API 키
사용자가 각자 자기 Claude API 키를 입력합니다. 키는 **해당 브라우저(localStorage)에만**
저장되고 서버로 전송되지 않으며, 호출은 브라우저 → Anthropic으로 직접 이뤄집니다.
(이 저장소에는 어떤 키도 포함돼 있지 않습니다.)

## 로컬 실행
- Windows: `start.bat` 더블클릭 → http://localhost:8000
- 또는 정적 서버 아무거나로 이 폴더 서빙

## 배포
정적 사이트라 Vercel에 그대로 배포됩니다 (빌드 불필요, 루트의 `index.html` 서빙).

## 요구사항
- 크롬(Chrome) — 음성인식(Web Speech API) 사용
- 마이크 권한
